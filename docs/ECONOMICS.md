# ECONOMICS

## 💰 1. Value of a Lead

Each audit reveals:
- AI spend inefficiency
- Usually $100–$1000/month waste range

If a user has:
- $300/month waste → they are high intent

**👉 Estimated value per qualified lead:**
$50–$200

*(because they are already overspending and likely to optimize)*

## 🔁 2. Funnel Breakdown

`Audit Completed` → `Email Captured` → `High Savings Detected` → `Credex Call` → `Purchase Credits`

**Conversion assumptions:**
- Audit → Email: 25–40%
- Email → Qualified lead: 10–20%
- Qualified lead → Credex call: 5–10%
- Call → Purchase: 20–30%

## 📊 3. CAC (Customer Acquisition Cost)

If organic distribution only:
- Reddit + X + communities = ~$0 CAC
- Time cost only

If scaled later:
- Paid ads CAC: $20–$80 (not used in MVP)

## 💵 4. Revenue Model (Credex Angle)

Credex earns via:
- AI infrastructure credit resale
- bulk discount arbitrage

Example:
- User overspends $300/month
- Credex saves them $150/month
- Credex takes margin on credits

## 📈 5. Path to $1M ARR

To reach $1M ARR:

Assume:
- 2000 paying users
- $500 average annual value per user

OR:
- 200 enterprise leads
- $5k–$10k value per deal
