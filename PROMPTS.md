# Prompts Used

This file documents the core prompts used during the development of this project.

1. **Initial Setup**: "Set up an Express backend with Mongoose and a React frontend. Resolve PostCSS conflicts with Tailwind v4 by downgrading to v3."
2. **Audit Logic Refinement**: "Implement 10 specific AI spending optimization rules in javascript. Chain them conditionally to ensure no random numbers or skipped reasons."
3. **UI Modernization**: "Redesign the Home page with a clean Glassmorphism UI, vibrant gradients, and a clear breakdown of monthly vs yearly savings."
4. **Shareable Architecture**: "Create an Audit schema using nanoid, attach emails later, and use react-router-dom to display a public report at /audit/:id without revealing PII."
